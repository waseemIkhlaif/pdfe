# PDFE

PDFE is a **simulation-only** Palestinian Digital Financial Ecosystem. It uses synthetic data and never connects to a real bank, payment network, blockchain or identity service.

> SIMULATION — NOT REAL MONEY / محاكاة — ليست أموالاً حقيقية
