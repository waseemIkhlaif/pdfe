# Wireframes

Greyscale low-fidelity sheets of the **skeleton** (the up-front wireframe set, FR-016a): one PDF per interface and language, every skeleton screen in five states (populated, empty, loading, error, permission-denied) at its primary size. Every other screen is wireframed the same way in the prototype (`docs/design/prototype/index.html#ID?mode=wire`), which also shows all five sizes. Regenerating adds tens of megabytes to the repository history: do it only when the design changes (`pnpm --dir scripts/design/render export`).
