# Keycloak realm `pdfe-demo`

> **SYNTHETIC.** Everything here is demo data for a simulation. The users are made up, the password is public, and the one-time-password secrets are public and fixed. None of it protects anything real. Do not reuse any of it anywhere.

The realm is code: [`realm-pdfe-demo.json`](./realm-pdfe-demo.json) is generated by [`generate-realm.mjs`](./generate-realm.mjs) (`node infra/keycloak/generate-realm.mjs`) and imported when the container starts. The API, the tests and `pnpm totp` read the same generator, so the users, subjects, tenants and secrets cannot drift apart.

## What the realm does

- **Roles.** One demo user per role in `packages/domain-types/src/rbac.ts`, plus two platform administrators (`demo.admin.a`, `demo.admin.b`) so that maker-checker can be tried with two people.
- **Second factor.** Users who hold a console role have the realm role `privileged` and must enter a one-time password (TOTP, 6 digits, 30 seconds). The other users sign in with the password alone. The API checks again: a privileged role on a token without `otp` in `amr` is refused with `MFA_REQUIRED`.
- **Token claims.** `sub` (the fixed subject below), `tenant_id` (the user's tenant, set by an administrator only), `amr` (`["pwd"]` or `["pwd","otp"]`, from the authenticators that completed) and `sid` (the session).
- **Clients.** `web-consumer` to `web-devportal`: confidential, Authorization Code with PKCE, redirect `http://localhost:300N/*`. `mobile`: public, PKCE, redirect `pdfe://auth`. `pdfe-tests`: direct grant, **only for tests and scripts**.
- **Address.** `http://localhost:8080` (through the gateway). The issuer is always that address, also for the API, which reaches Keycloak at `http://keycloak:8080` and accepts both.

## Tenants

The IDs are fixed, because the realm carries them in the `tenant_id` claim and the seed creates the tenants with the same IDs.

## Running it

- `pnpm dev:all` starts it with the rest of the stack (health: `http://localhost:8080/realms/pdfe-demo`).
- Integration tests start their own copy with Testcontainers (`startKeycloak()` in `@pdfe/test-kit`).
- The admin console is at `http://localhost:8080/admin` (user `admin`, password `KEYCLOAK_ADMIN_PASSWORD` from `.env`).
- The login theme folder `themes/pdfe` is mounted for the navigable-shells story.
